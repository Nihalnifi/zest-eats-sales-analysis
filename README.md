# Zest Eats Sales Analysis

## Project Overview

This project focuses on analyzing Zest Eats sales data using SQL to understand sales performance, customer behavior, product performance, and other business-related metrics.

The analysis was performed using SQL queries to extract useful information from the dataset and answer different business questions.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Dataset

The project uses an e-commerce dataset containing information about:

* Customers
* Products
* Orders
* Order Items
* Payments
* Shipments
* Reviews

The dataset contains approximately 900 orders.

## Analysis Performed

The project includes SQL analysis related to:

* Sales and revenue analysis
* Customer analysis
* Product performance
* Order analysis
* Payment analysis
* Shipment analysis
* Customer reviews
* Top-selling products
* Business performance metrics

## SQL Concepts Used

The project demonstrates the use of:

* SELECT and WHERE
* ORDER BY
* GROUP BY
* Aggregate Functions
* JOINs
* CASE WHEN
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Date Functions
* HAVING
* Business-oriented SQL queries
